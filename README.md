# MoonlightFP

Локальное расширение для Brave на Manifest V3. Оно добавляет вкладку MoonlightFP в верхнюю навигацию FunPay; настройки, автоподнятие и статистика доступны прямо на сайте.

## Установка в Brave

1. Открой `brave://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери папку проекта.
4. Открой FunPay и закрепи MoonlightFP на панели расширений.

## Текущее поведение

- По умолчанию расписание выключено.
- Минимальный период — 240 минут.
- Вкладка MoonlightFP добавляется рядом с «Продажи», «Покупки» и «Сообщения»; popup расширения служит переходом к ней.
- Доступны темы Moonlight, Firewatch, Red Moon и Ocean.
- Шрифт меняется локально для текста FunPay: Copperplate Gothic Light применяется к доступным латинским символам, Bookman Old Style — запасной шрифт для кириллицы. Также доступны Cinzel, Georgia и Gabriola.
- Статистика читает продажи (`/orders/trade`) и покупки (`/orders/`) через текущую сессию Brave, учитывает язык текущей страницы и отображает суммы по валютам и периодам.
- Расширение хранит только настройки и локальный статус в `chrome.storage.local`.
- Данные заказов не сохраняются; статистика ограничена 100 страницами на каждый тип заказов за один сбор.
- Использует штатные кнопки FunPay `button.js-lot-raise`; ручной запуск и расписание доступны во вкладке MoonlightFP.
- Проверяет, появился ли новый запрос `/lots/raise`, и сообщает о новом сообщении об ограничении FunPay. Между группами сделана пауза 3,5 секунды.
- Авторизация выполняется обычной страницей FunPay в Brave; расширение не запрашивает пароль или cookie.

Расширение ищет установленные в Windows гарнитуры Copperplate Gothic Light/Bold через локальный источник шрифта; сами файлы шрифтов не копируются в проект.

Поднятие отправляет штатные запросы FunPay и может быть ограничено таймером площадки. Доступен минимальный интервал 240 минут; расписание выключено по умолчанию.
